# Changelog

## v0.6.0
- Add support of value only slitting in rml preprocessor
- Add option ``strict_splitting`` to bypass conditional iterator after
- Fix handling of empty schema like {} in API postprocessing
- Update ``requests`` and ``pydantic`` dependencies to more recent versions

## v0.5.0
- Change the API extension module to link request nodes directly to entity nodes.
- Fix default namespaces (like rdf, rr, etc.) are not always added in the generated RML mapping file.
